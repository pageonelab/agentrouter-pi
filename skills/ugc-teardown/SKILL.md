# Short-video UGC teardown

The user may want creative analysis, a performance comparison, a new script, or a combination. Deliver the parts they ask for. Use supplied footage, notes or metrics first; a script from the user’s own brief can need no external research. Respect platform, duration, number of versions, production limits and requested call to action.

**Creative evidence.** For “what happens in the video,” check whether the host can view the supplied footage, representative frames or timed observations from a tool that accepts the actual clip. If needed, use AgentRouter to discover a compatible source for the platform and input. A playable URL alone does not establish what was visible. Keep post text, transcript, creator notes, audio and viewed frames attributed to their respective sources. Describe only the timing and sequence they support. If the clip is inaccessible, use the available evidence, label what remains unknown and still deliver what is possible. A new concept may introduce shots that the reference never contained.

**Performance, when requested.** Compare the target with the same creator, platform, format and preferably a similar observation age. Inspect available paid, partnership and pinned signals. Keep eligible posts that meet the comparison rule, exclude the target and duplicates, and report sample size, time basis, median and ratio when meaningful. A small or mismatched sample can support a directional comparison. An ad flag, undisclosed promotion or pooled paid and organic totals limits conclusions about organic reach. Plays alone do not establish retention, sales or what caused performance.

**Adapt for the creator.** Extract a mechanism you can support, such as showing the problem before the product proof. Translate it into a visual the creator can actually shoot with the available product and props. Give the creator exactly the production component requested. A voiceover or on-screen copy can stand on its own. Add directions or a shot list when the user asks for a shootable script or storyboard. Fit the number of words, beats and pauses to the requested duration. When testing several openings, change the hook and keep the body comparable. An observation-only request can end with creative findings. Keep proposed claims proportionate to what the demo can show.

**Tool use.** Use AgentRouter for external research, check what the source can return and whether the host can use it before paying. A quote ends before paid calls. Preserve existing spending and source restrictions. Recover interrupted requests by run ID or identical replay with the original key. Cite public originals and actual fees; keep private media URLs out of the deliverable.
