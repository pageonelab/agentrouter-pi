# Job shortlist

Use the candidate’s stated experience, eligibility and preferences. Search with role, skills and location; keep their identifying details and résumé out of provider requests. Distinguish constraints from preferences. An as-of date is not a posting-age limit. When the user supplies openings, check those first.

**Find a pool worth checking.** For “can apply now,” use an AgentRouter web search across employer careers sites and recruiting platforms relevant to the market. Search by role family or local title and location first. Use a distinctive skill, seniority or site filter when it improves precision; requiring every résumé keyword can hide good matches. An employer’s board, a jobs index and a web search cover different populations. Use them as complements. If indexed jobs repeatedly close or redirect to a generic page, switch to an employer’s current openings list or public recruiting-board feed. Select live role IDs there, then open the individual postings. When jobs are live but a requirement repeatedly rules them out, change the search terms or the employer pool instead. If too few qualify and a materially different authorized route is available, try it. Stop once the requested shortlist is supported or further checks are unlikely to help.

**Check the role and the destination separately.** Read the matching employer posting or their recruiting platform. Check duties, required versus preferred qualifications, seniority, geography, remote eligibility, on-site frequency, language and employment terms where they affect this candidate. A broad “remote” tag can hide a payroll restriction. A form question alone does not establish a rejection rule. When sources conflict, prefer the role-specific current text and flag unresolved hard conditions.

For requests to apply now, follow the employer’s application link to that exact role. A matching form with fields or an upload is form-verified. An official listing behind login, a blocked form or an uninspected Apply button is officially listed, form unverified. A third-party listing alone is a lead. Remove closed or mismatched roles. Do not submit anything.

**Make the decision useful.** For each recommended opening give the original link, date checked, job-specific fit and material risk. Count a role as ready when its application is verified and the supplied profile supports the material hard requirements. A missing mandatory credential, skill or geographic condition makes it conditional; a preferred skill or an ordinary interview question need not disqualify it. A known conflict is an exclusion. List worthwhile conditional options separately, with the precise fact that would change the recommendation. If none qualify, say zero. If the user is comparing leads rather than asking for verified forms, use the evidence level they requested.

**Tool use.** Check current prices and use existing authorization. Stop at a quote for a preview. Recover an interrupted request by run ID or identical replay with the original key. Give actual research fees and gateway run IDs for paid lookups when reporting receipts. A local evidence reference is not a gateway receipt.
