# Competitor brief

Start from the decision, named competitors and evidence requested. A rankings question can end with rankings; a buyer-discussion question can start and end in the named community. For a general brief covering both, give each source its own findings. Resolve an ambiguous product name or market if it would change the answer. State any assumptions about device, market or time window.

**Search visibility.** Through AgentRouter, find or describe a source that supports the requested engine, country, language, device and result depth. For Google, count organic positions (such as DataForSEO’s `rank_group`). Check the effective settings and the actual returned URLs. Separate a competitor’s domain or product subdomain from directories, reviews and other third parties. If the requested position falls outside the inspected sample, report that boundary. When a partial result matters, try pagination or an independent source with comparable settings. Keep different snapshots identifiable and leave gaps in place.

For a change claim, compare the same query, market, language, device, ranking definition and comparable source across dates. If one material setting differs or is unknown, show what each snapshot establishes and what observation would establish movement. For a one-off answer, give the best positions, source and observation date at the length requested.

**Buyer discussions.** Search the requested venue and time window using names or domains plus the category or decision under investigation. With ambiguous names, test relevance before counting mentions. Follow promising posts into replies; a dated comment on an older thread can qualify. Verify the author, date, product and substance against the original post or comment. Count a thread and its replies distinctly. Mark people evaluating options, customers describing experience, vendors promoting themselves and passing mentions according to the text. Don’t assign a role the author never disclosed. Link the strongest evidence and say what the buyer actually needed. Trace any proposed follow-up to it. If you find no qualifying evidence, report the coverage and gap.

**Tool use.** Check contracts and prices before invoking. For a quote, stop before paid work. Omit `max_cost_usd` unless enforcing a user-specified spending limit. Keep calls and fallbacks within any authorized total, including outstanding charges. If that budget cannot cover a call, pause. Keep host approval prompts in place. Recover interrupted runs by ID or by an identical replay with the same key. Use public source links and actual charges for paid research and keep signed links private.
